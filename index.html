        // sobre
        
Estudante full-stack

      

      

        

          
Sou Marcus Leal, estudante full-stack de Teresina, PI. Atualmente curso Análise e Desenvolvimento de Sistemas na UNINASSAU e coloco em prática, nos meus projetos, o que aprendo em sala.

          
Gosto de construir a aplicação inteira: da interface que a pessoa usa até o banco de dados e a API que ficam por trás. Hoje trabalho principalmente com JavaScript, TypeScript, React e Node.js, usando PostgreSQL e Supabase para guardar os dados.

          
Meus projetos nascem de problemas reais: calcular o imposto do salário, organizar os clientes de um negócio e, no Gestão Que Transforma, ajudar pequenos empreendedores a encontrar apoio em finanças, marketing e gestão.

          
Também estudo como integrar inteligência artificial às aplicações com a API da Anthropic (Claude), sempre com foco em lógica de programação e estrutura de dados bem feitas.
